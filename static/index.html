Available Tools

          

          
This MCP server exposes the following tools for AI agents:


          

            

              convert_pdf_to_markdown
              Tool
            

            
Convert a base64-encoded PDF file to clean, structured Markdown.

            

              
Parameters

              

                pdf_base64
                string
                required
                
The PDF file content encoded as a base64 string.

              

              

                filename
                string
                optional
                
Original filename for title detection. Defaults to "document.pdf".

              

            

            

              
Returns

              
JSON string with markdown, title, and stats (token counts, savings percentage, timing).

            

          


          

            

              convert_pdf_from_url
              Tool
            

            
Download a PDF from a public URL and convert it to clean Markdown.

            

              
Parameters

              

                url
                string
                required
                
Public URL of the PDF file to download and convert.

              

              

                filename
                string
                optional
                
Filename for title detection. Auto-detected from URL if not provided.

              

            

            

              
Returns

              
JSON string with markdown, title, and stats (token counts, savings percentage, timing).
